# La Taverne — Front-end (Next.js)

Tableau de bord du Maître du Jeu, développé avec Next.js (App Router).
Il tourne sur **http://localhost:3001** et consomme l'API Express du dossier parent.

L'installation complète (API + Front) est décrite dans le [README principal](../README.md).

```bash
cp .env.example .env.local   # adresse de l'API
npm install
npm run dev                  # http://localhost:3001
```
